首页 / 出海路径自查

你卡在哪一步

来咨询的企业，八成卡在同一个地方：不知道下一步该做哪个动作，于是先找人报价，报完发现路径是错的。这张图按四个阶段自查——先确认自己在第几步，再看这一步要办什么、要准备什么、最容易卡在哪。顺序比价格重要，路径错了，钱花了还得重来。

01主体还没定用哪国公司签约、收款 02产品要进关认证没做，货到港进不去 03要上平台建品牌本土店、商标、品牌备案 04已经在卖税务、年审、变更、申诉

01　主体还没定：先解决"谁签约、谁收款"

自查：如果你现在用国内公司收美元、或者在纠结"到底该在哪个国家设公司"，就是这一步。

要办的事你要准备什么交付什么最容易卡在哪
境外公司注册（印尼 PT PMA / 马来 Sdn Bhd / 泰国 / 菲律宾 SEC / 越南 / 新加坡 / 香港）股东与持股结构、经营范围、注册资本、法定代表人的居留安排营业执照或注册证、税号、公章、银行开户指引经营范围与外资负面清单不匹配；本地董事不到位
ODI 境外投资备案境内主体审计报告、投资方案、资金来源说明发改委备案、商务部门《企业境外投资证书》、银行外汇登记先汇了钱再补备案，资金路径说不清
银行开户与税务登记注册证、章程、董事证件、业务合同或意向书对公账户、税号、发票资质开户时业务说明与经营范围对不上

02　产品要进关：认证不做，货到港就没法清关

自查：主体有了，产品要往目标国发第一批货——这一步决定货能不能进。

品类常见认证你要准备什么最容易卡在哪
化妆品 / 护肤印尼 AKL、泰国 FDA、菲律宾 FDA、马来 NPRA配方、成分安全性资料、标签稿、本地责任人技术文件能复用，本地责任人和标签语言不能
食品 / 保健印尼 BPOM、马来 FOSIM、泰国 FDA 备案、菲律宾 LTO+CPR配方工艺、工厂资质、原产地证、本地进口商马来是逐批申报，不是一次注册长期有效
电器 / 电子印尼 SNI、泰国 TISI、马来 SIRIM、菲律宾 PS/ICC安规测试报告、工厂质量体系文件、样品受管清单判断错，做完发现还要工厂审查
无线 / 通信印尼 SDPPI、马来 MCMC射频与 EMC 测试报告、本地代理只做 SIRIM 不做 MCMC，蓝牙产品照样被扣
医疗器械马来 MDA、泰国 FDA、菲律宾 FDA技术文档、临床或性能资料、本地授权代表风险分级定错，审评路径整条重来
清真相关印尼 Halal（BPJPH）、马来 Halal（JAKIM）原料清真性证明、生产体系文件、现场审核配合原料供应链有一环说不清，整套要重审

03　要上平台建品牌：商标不先占，后面都是替别人做嫁衣

自查：产品能进关了，接下来是本土店入驻、品牌备案、商标布局。

要办的事你要准备什么交付什么最容易卡在哪
东南亚商标注册（印尼 / 马来 / 泰国 / 菲律宾 / 越南）商标图样、类别与商品项、使用证据受理号、注册证类别选窄了，实际卖的第二类没保护到
本土店入驻资料本地主体、税号、品牌资质、类目许可店铺开通、类目权限用跨境主体去申本土店，资质层级不够
品牌备案商标注册证或受理号、品牌授权链品牌备案通过、防跟卖权限商标还只在申请中，备案被卡

04　已经在卖：合规维护比拿证更容易被忽略

自查：店铺在跑，货在卖，但续期、申报、变更没人盯。

要办的事你要准备什么交付什么最容易卡在哪
税务申报（VAT / PP30 等）销售流水、进项票据、报表申报回执、完税凭证逾期罚则按天算，补报成本远高于按期
年度维护与年审年报资料、财务报表、股东变更记录年报回执、存续证明忘记年报被列入异常，恢复要跑窗口
主体变更（法人 / 股东 / 地址 / 资本）变更决议、公证认证文件变更登记回执变更后未同步到税务、银行、平台
平台申诉与合规整改处罚通知、整改方案、资质补件申诉材料包、整改报告只交整改说明，没交资质原件

三步判断法：拿不准自己在哪一步时

第一步，问"货能不能进"

如果产品还没有目标国的合规凭证，无论主体办得多漂亮，第一批货都进不去。这一步优先于公司注册之外的所有事。

第二步，问"钱能不能合法收"

主体、账户、税号三件套齐了没有。缺一件，收款路径就不闭环，后面做多大都是悬着的。

第三步，问"品牌有没有保护"

商标是按国、按类保护的。东南亚五国没有"一次注册全域生效"这回事。卖起来再补，大概率已经被别人先占了。

不确定自己在第几步？把情况说清楚

告诉我们三件事：目标国家、产品品类、现在办到哪了。我们判断路径，再谈材料——路径错了，材料准备得再全也要重来。
